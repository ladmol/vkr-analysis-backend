# Аналитический каталог MVP

Семантический каталог определяет, какие данные пользователь может использовать в конструкторе отчетов. Frontend не работает с физическими колонками БД напрямую: он получает список разрешенных полей через `GET /analytics/fields`.

## Группировки

Поля, которые можно использовать как измерения:

- `full_name` - ФИО, доступно только `admin` и `operator`;
- `status` - статус кандидата или курсанта;
- `course` - курс из учебной группы;
- `student_course` - курс из записи студента;
- `study_group` - учебная группа;
- `institute` - институт;
- `specialty` - направление подготовки;
- `military_specialty` - военно-учетная специальность;
- `military_commissariat` - военный комиссариат;
- `platoon` - взвод;
- `medical_result` - результат медосвидетельствования;
- `fitness_category` - категория годности;
- `psycho_category` - категория профпригодности.

## Метрики

Поля, которые можно агрегировать:

- `student_count` - количество записей, агрегация `count`;
- `grade100` - балл успеваемости, агрегации `avg`, `min`, `max`;
- `final_result` - итоговый балл, агрегации `avg`, `sum`, `min`, `max`;
- `total_points` - сумма баллов физподготовки, агрегации `avg`, `sum`, `min`, `max`;
- `strength_points` - баллы за силу, агрегации `avg`, `sum`, `min`, `max`;
- `speed_points` - баллы за быстроту, агрегации `avg`, `sum`, `min`, `max`;
- `endurance_points` - баллы за выносливость, агрегации `avg`, `sum`, `min`, `max`.

## Фильтры

Фильтровать можно по группировочным полям и числовым показателям:

- строковые поля: `eq`, `in`, `contains`;
- числовые поля: `eq`, `in`, `gte`, `lte`;
- дата-поля при добавлении в каталог: `eq`, `in`, `gte`, `lte`.

## Роли

- `admin` видит все поля;
- `operator` видит все поля, кроме будущих административных ограничений;
- `observer` не видит чувствительные персональные поля, например `full_name`.

## Ограничения MVP

- максимум 2 метрики в одном запросе;
- максимум 2 группировки в одном запросе;
- максимум 3 правила сортировки;
- лимит результата от 1 до 500 строк;
- пользователь выбирает только поля из каталога, произвольные SQL-колонки недоступны.
